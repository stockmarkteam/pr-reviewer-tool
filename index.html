PRレビュアールーレット 負荷が少ない人ほど当たりやすい抽選

使い方（クリックで開く）

① 全体TODOページの「unstructured PR 管理DB」の表で、PR 列の一番上のセルをクリック → 一番下の行の status 列（またはそれより右）のセルを Shift+クリックしてセルを選択 → Cmd+C（Windows は Ctrl+C）でコピーし、下の欄に貼り付けて「読み込み」（会議冒頭に1回）。行の左端のチェックボックスで選ぶと PR 名しかコピーされないので使わないでください。
② 「ready-for-review」でレビュアー未記入のPRが一覧に出るので1件選ぶ（作成者は自動で除外）。merged・closed のPRは負荷に数えません。
③ 休暇の人・今回対象外の人にチェック。④ 回す → 当選者名をDBのレビュアー欄に記入。
メンバーの恒久的な追加・削除は、埋め込みURLの ?m=名前1,名前2,… を書き換えてください。

1PR管理DBを貼り付け 貼り付けなしでも全員負荷0で抽選できます
未読み込み
2PRを選ぶ ready-for-review かつレビュアー未記入のPRのみ
3除外する人にチェック 作成者は自動除外・変更不可
4ルーレット 扇の大きさ＝当選確率

このページはデータを保存しません。貼り直すと表の内容で負荷を再集計します。URLに ch（同期チャンネル）を設定した場合のみ、端末間で暗号化した状態を中継サーバー（ntfy.sh）経由で共有します（名前・PR名は暗号化され、サーバーでは読めません）。未設定時は外部送信ゼロです。
